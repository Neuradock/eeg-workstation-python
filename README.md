# NeuraDock EEG Workstation Python

Python tools and examples for reading, recording, and working with NeuraDock EEG data.

## Contents

- Data reading examples
- Real-time streaming examples
- EEG plotting examples
- Basic preprocessing examples

## Example Files

| File | Description |
|---|---|
| `examples/read_stream.py` | Read real-time EEG stream |
| `examples/record_eeg.py` | Record EEG data |
| `examples/plot_eeg.py` | Plot EEG signals |
